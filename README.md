# Mi Incentivo

PWA de seguimiento de ventas e incentivos para promotores Mercado Pago Retail.

Cada promotor entra con una clave personal. Los datos del corte se publican cifrados; las claves y las hojas fuente no se incluyen en este repositorio.

Los importes son aproximados y pueden cambiar después de la auditoría final al cierre de mes. La información se actualiza al publicar un nuevo corte; no es una conexión en tiempo real con Google Sheets.
